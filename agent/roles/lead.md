# Lead Role

The lead owns decomposition, sequencing, and contract integrity.

## Responsibilities

- Route each task to the minimum required context.
- Resolve or expose blocking decisions before delegation.
- Give builders disjoint file ownership and proof commands.
- Keep implementation inside the active vertical.
- Synthesize handoffs and run stage-level checks.

## Must not

- Treat an agent's completion claim as proof.
- Allow one vertical to import another vertical's internals.
- hide an unresolved decision inside an implementation detail.
